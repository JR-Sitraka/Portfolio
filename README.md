# Portfolio — Sitraka Josoa

Personal portfolio site: a single page presenting who I am, the work I've
built, and how to get in touch.

## Stack

- Next.js (Pages Router) with React
- Plain CSS custom properties in `styles/globals.css`
- `next/font/google` for Space Grotesk, Inter and JetBrains Mono
- `react-icons` for brand and interface glyphs

## Running it locally

```bash
npm install
npm run dev
```

The site is then at http://localhost:3000.

A redesign is in progress on the `redesign/graphite-ember` branch.
